# Dream_of_the_Red_Chamber
87版红楼梦信息汇集

最近花时间看完了87版本的红楼梦电视剧，里面有很多人物不是太了解是做什么的，刚开始看的很是吃力。
同时对最后的结局也是很唏嘘，对当时的演员也心生敬佩，在网上找了一圈发现了一些资料，但是都不太符合自己的预期，所有使用豆包简单整理了这个静态网站。
当然有一些信息还没有完成（图库中演员图片的收集，英文），希望大家下载后自己可以继续。

这些信息大多都集中在豆瓣，百度百科等网站上。
